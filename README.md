# Suhani Kumari — Personal Portfolio

A modern, responsive personal portfolio website built with **React + Vite** and deployed on **Vercel**. It showcases my background, skills and projects with a clean, animated dark-themed UI.

## ✨ Features

- Animated hero with typewriter role text and gradient background orbs
- Responsive layout (mobile → desktop) with an accessible mobile menu
- Scroll-reveal animations and smooth in-page navigation
- Sections: Home, About, Skills, Projects, Contact
- Fast, dependency-light build powered by Vite

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, JavaScript (ES2020+)
- **Styling:** Modern CSS (custom properties, grid, flexbox, glassmorphism)
- **Icons:** react-icons
- **Deployment:** Vercel

## 🚀 Getting Started

```bash
# install dependencies
npm install

# start the dev server
npm run dev

# create a production build
npm run build

# preview the production build
npm run preview
```

## 📁 Project Structure

```
suhani-portfolio/
├─ public/            # static assets (favicon)
├─ src/
│  ├─ components/     # Navbar, Hero, About, Skills, Projects, Contact, Footer
│  ├─ data.js        # editable content (profile, skills, projects)
│  ├─ App.jsx        # page composition
│  ├─ main.jsx       # entry point
│  └─ index.css      # global styles & design tokens
├─ index.html
└─ vite.config.js
```

## ✏️ Editing Content

All text content (name, skills, projects, contact links) lives in [`src/data.js`](src/data.js) — update that single file to change what the site shows.
